# Faqra: Windows re-implementation of Vorssaint (Stage 1)

## Context

Vorssaint (github.com/vorssaint/vorssaint-utils) is a free, GPL-3.0 macOS menu bar toolkit: one status-bar icon fronting 66 features (per-app mixer, system monitor, app switcher, window snapping, clipboard history, snippets, shelf, screenshots, recorder, command bar, a "Dynamic Island"-style notch panel, and more). The user forked it as **Tigertay0/vorssaint-utils-windows** (a clean copy of upstream, no extra commits) and wants the same app on Windows 11: same features, same tray-icon entry point, same always-on-top panel at the top of the screen that expands when the mouse touches it.

**Why this is a rewrite, not a conversion.** The upstream is ~196K lines of Swift/SwiftUI/AppKit with zero cross-platform layers; all 42 services call macOS-only APIs (CoreAudio, Accessibility, ScreenCaptureKit, AppleSMC, private MediaRemote/SkyLight). Nothing compiles that to Windows. The Windows app is therefore a from-scratch re-implementation that uses the Swift source as the specification and mirrors it feature by feature, screen by screen, setting by setting (same feature ids, same settings keys, same panel sections, same timings). Nothing new is invented; where Windows has no equivalent (Dock, Finder, Homebrew, notch hardware, SMC fan daemon) the feature is classified not-applicable and hidden.

**Legal.** Code is GPL-3.0-or-later, so the port is GPL-3.0 too and keeps upstream copyright headers and attribution. `TRADEMARKS.md` forbids unofficial builds from using the Vorssaint name, logo, icon, bundle identity, or update feed, so the Windows app is named **Faqra** with its own icon and its own GitHub release feed.

## The spec to mirror (exploration findings)

Swift paths are relative to `Sources/Vorssaint/`.

### Menu bar icon (`App/StatusItemController.swift`, `App/AppDelegate.swift:83-98, 370-432, 1155-1233`, `App/MenuBarRenderer.swift`)
- One status item: 26x20 pt icon; optional keep-awake countdown text; optional live metrics text (monospaced, labels `CPU GPU RAM DSK BAT PWR RPM`, network as a two-line `↓/↑` block). **Metrics are off by default** (`Defaults.swift:1218-1230`); the icon ships clean. Icon variants: idle, keep-awake-active (user-chosen symbol), blue "update available", red mic-muted badge. Optional `menuBarSeparateMetrics` mode gives each metric its own status item.
- Left click → popover panel anchored under the icon, `applicationDefined` (no auto-dismiss on focus loss), custom fade, closes on outside click / Esc. Right click → keep-awake toggle if that option is on, else context menu in this order: Enable/Disable keep awake; Activate for ▸ (15 min, 30 min, 1 h, 2 h, 4 h, 8 h, Indefinitely; only when inactive); Cleaning mode; separator; Settings… ; About; Uninstaller; Shelf; Check for updates; separator; Quit.
- Panel (`UI/MenuPanel/PanelLayout.swift:12-14`, width 332): sections keepAwake, brightness, mixer, system, network, disk, power, fanControl, utilities, controls, toggles. Reorderable (comma-joined order; new sections slot into canonical position: disk after network, controls after utilities, brightness after keepAwake), collapsible (comma-joined set), hideable per visibility key, each gated by a feature list (`featureGate`, lines 77-98).

### Island / notch (`Services/Notch/NotchService.swift:392-443, 829-877, 1109-1203`, `NotchSupport.swift:7-90, 336-390, 471-474, 606-616, 653-704, 771-829, 874-883`, `NotchWindowHost.swift:38-58, 260-273, 472-477, 563-583`, `UI/Notch/NotchView.swift:36-85, 161-216`, `Core/Defaults.swift:1099-1133`)
- Display: automatic → notched built-in → any notched → menu-bar screen. Non-notch displays draw a **fake notch**: width `180 * menuBarHeight / 32` (≈135 pt at 24 pt bar), height = bar height, cap 70% screen width, horizontally centered, flush with top edge. Trigger = the silhouette only (hit-test clipped to the notch path), not the whole top edge.
- Hover: 100 ms dwell → full open if `notchHoverExpands` (default true) else peek; gated by `notchOpenOnHover` (default true). Leave → collapse after 180 ms (expanded) / 120 ms (peek), only if opened by hover. Pin disables hover-close. Also opens on click and scroll-down; collapses on outside click, Esc, chevron, scroll-up. Hover-open never takes focus; click-open does.
- Expanded: width 480 compact / 560 spacious (default) / 360–600 custom; height per module, cap screen − 48. Header: sections-grid button, title, ⋯ menu (Pin/Unpin, Settings), chevron-up. Modules (reorderable/hideable): controls, mixer, music, clipboard, captures, files, system, tools, calendar, notifications, timer, camera, downloads. Idle content default `music` (album art + equalizer bars), fallback battery. Optional 44 pt quick-access buttons in 72 pt gutters.
- Animation: spring, 0.34 s grow / 0.26 s shrink, content cross-fade 0.18 s, reveal/dismiss 0.40 s; respects Reduce Motion.
- Window: borderless non-activating panel, above status items, all Spaces + over fullscreen, excluded from app cycling, clear background, forced dark. Keys: ⌘K sections, ⌘⌥letter jump, ⌃Tab/⌃⇧Tab, Esc.

### Architecture (`Core/FeatureCatalog.swift`, `Core/FeaturePresets.swift`, `App/FeatureRuntime.swift`, `Core/Defaults.swift`, `Core/SettingsBackupSupport.swift`, `Core/GlobalShortcut.swift`, `UI/Settings/SettingsView.swift`, `UI/Settings/FeatureHubSettings.swift`, `UI/Onboarding/OnboardingView.swift`, `Services/CommandBar/*`)
- `AppFeature`: 66 stable raw values, 7 groups. Per feature: symbol, availability key `featureAvailable.<raw>`, enabled keys (empty = on-demand), permissions, energy profile. Availability defaults all true except focusFollowsMouse, fanControl, diskImageInstaller, killProcess; clean install applies the **Essential** preset (mixer, keepAwake, 6 monitors). Presets: essential, windows, battery.
- `FeatureRuntime.bindings`: dictionary of lazy closures; a feature's singleton is never instantiated unless its closure runs; `syncAtLaunch` runs only available features; uninstall never deletes settings; `needsRestartToUnload` + relaunch.
- Every service: `static let shared` + idempotent `syncWithPreferences()`.
- One `DefaultsKey` registry (~700 keys), registered defaults, `sanitized*` validators, migrations. Backup = registered ∪ availability ∪ unregistered-preference keys − machine-state keys, plist envelope `vorssaintBackupVersion`/`vorssaintBackupAppVersion`. Launch at login: intent key + repair at startup.
- Settings window: sidebar 198–240 with search + detail, min 772x528, `SettingsPage` enum, `SettingsRouter`, shared `SettingsDirectory` also read by the Command Bar. Feature Hub: Features/Permissions segmented control, "N of M on", Install all/Uninstall all, restart banner, preset cards, grouped rows with Install/Uninstall + energy badge.
- Onboarding: steps welcome → purpose (preset/feature pick) → permissions → done; `onboardingStep` persisted; `hasOnboarded`.
- Command Bar: non-activating panel on ⌥Space (`commandBarShortcutEnabled` default false); modes search/argument/confirm/actions/naming/capturingShortcut; static catalog (actions, toggles auto-generated from boolean prefs, settings pages, snippets, links) + dynamic providers merged at query time; ranking memory.
- Localization: Swift struct per language, 13 locales, user-selectable. Build: `--selftest` gates release; `--uninstall` CLI.

### Windows portability of all 42 services
- **Direct (A):** Audio, Clipboard, Snippets, KeyboardDebounce, MouseClickDebounce, MouseButtons, MouseNavigation, SuperKey, CleaningMode, QuitProtection, WindowLayout, Switcher, KillProcess, SystemMonitor, Metrics, Cleaner, Uninstall, Update, AppUpdates, Feedback, ManagedDownloads, Media, Recorder, QuickTools (screenshot/OCR/QR), Shelf, CommandBar, MouseExceptions, FocusFollowsMouse, Display brightness, AutoQuit.
- **Approximate (B):** RadialMenu, Notch content, DockPreview, MiddleClick, MouseAcceleration, extra brightness, FanControl, Bluetooth sleep, DiskImageInstaller (→ MSI/MSIX), peripheral battery.
- **Not applicable (C):** DockClick, Finder cut/paste/rename, Homebrew, notch hardware layer, FanControlHelper (SMC), NowPlayingAdapter (Windows has public GSMTC), HIDEventSystem/VMStatisticsCompat, SkyLight dark-mode toggle, Switcher SpaceHop internals.
- Windows needs none of macOS's consent grants for hooks; elevation only for fan control, scancode-map writes, Program Files uninstalls.

### B. Scope items and Windows mechanisms

1. **Tray icon** (mirrors `StatusItemController`, `MenuBarRenderer`, `AppDelegate.presentContextMenu`). `Shell_NotifyIcon` v4 with a stable `guidItem`, message-only HWND; `NIN_SELECT` → popover, `WM_CONTEXTMENU` → Win32 `TrackPopupMenuEx` (must `SetForegroundWindow` first and `PostMessage(WM_NULL)` after). Re-add on `TaskbarCreated`. `ContextMenuBuilder.Build(state)` returns an ordered list (unit-testable) in the exact upstream order, with Cleaning mode / Uninstaller / Shelf omitted until their features exist. Metrics: a tray slot is one 16x16-at-DPI icon, so upstream's `menuBarSeparateMetrics` mode becomes the only mode: one extra tray icon per opted-in metric, each rasterized (`DrawingVisual` → `RenderTargetBitmap` → HICON) as a two-line label/value glyph with monospaced digits; full text in the tooltip. Default stays **metrics off** like upstream. Keep-awake active variant + countdown in tooltip and icon.
2. **Popover panel** (mirrors `PanelLayout.swift`, `MenuPanelView.swift`, section views). `MenuPanelWindow : PopupWindowBase`: borderless, `WS_EX_TOOLWINDOW`, activates (needs Esc + mixer input), positioned above the tray rect (`Shell_NotifyIconGetRect`) clamped to the work area, height cap work-area − 24, 120 ms opacity fade, **no close on Deactivated**; outside click via `WH_MOUSE_LL` hook active only while visible (ignores the tray rect); Esc closes. Transparency via `WindowChrome` + `DwmExtendFrameIntoClientArea` + `DWMWCP_ROUND` (hardware path; avoid `AllowsTransparency`). `PanelSectionId` (11 raw values) + `PanelLayout` order/collapsed/visibility ported verbatim; Stage 1 renders keepAwake, mixer, system, network, disk, power; others exist as hidden placeholders gated by not-applicable features.
3. **Island pill** (mirrors `NotchService`, `NotchSupport`, `NotchWindowHost`, `NotchView`). `IslandGeometry` ports `NotchGeometry(isNotched:false)`: resting 135x24 DIP (bar height 24), DPI-scaled, top-center of `notchDisplay` (automatic → primary; `builtIn` sanitized to automatic). `IslandWindow`: `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW | WS_EX_TOPMOST`, `ShowActivated=false`, black rounded-bottom path, DWM transparency. Hover: WPF Enter/Leave plus a 50 ms cursor poll while expanded; `IslandHoverState` ported; dwell 100 ms, collapse 180/120 ms; Pin disables hover/outside close. Focus model = upstream's `takeFocus` split: hover never activates; click/Ctrl+K/Ctrl+Tab activate via `SetForegroundWindow` and `ForegroundRestorer` returns focus on collapse. Motion: `IslandMotion.Duration` 0.34/0.26 s, window rect animated per frame via `SetWindowPos` on `CompositionTarget.Rendering` with spring-like easing; content cross-fade 0.18 s; honor `SystemParameters.ClientAreaAnimation` for Reduce Motion. Header: sections grid, title, ⋯ (Pin/Unpin, Settings), chevron. Stage 1 modules: controls, mixer, system, timer (all 13 raw values kept in `IslandModule`). Idle: `NowPlayingService` over `GlobalSystemMediaTransportControlsSessionManager` (album art + 3 equalizer bars), fallback battery %. `TopmostGuard` re-asserts `HWND_TOPMOST` on `EVENT_SYSTEM_FOREGROUND`, display/setting changes, 5 s heartbeat. `FullscreenDetector` (`SHQueryUserNotificationState`) hides the pill during exclusive-fullscreen apps. Virtual desktops: documented `IVirtualDesktopManager.IsWindowOnCurrentVirtualDesktop` + hide/re-show on desktop switch (undocumented pinning left behind a flag).
4. **Settings window** (mirrors `SettingsView`, `SettingsDirectory`, `SettingsPage`, `FeatureHubSettings`). Sidebar column 210 (198–240 via splitter) with search + grouped list, detail `ContentControl`, min 772x528, size persisted as machine-state keys. `SettingsPage` keeps every upstream case; Stage 1 pages: General, Features, Menu Bar (tray), Island, Mixer, Keep Awake, Monitor, Shortcuts, Advanced (backup), About. Feature Hub: Features/Permissions segmented control (Permissions tab informational on Windows), "N of M on", Install all/Uninstall all, restart banner, preset cards (Windows/Battery cards disabled with "coming soon" until their features are supported), grouped rows with Install/Uninstall, energy badge, Windows-support badge, blocked-reason tooltip.
5. **Onboarding** (mirrors `OnboardingView`). Steps welcome → purpose (preset cards + feature checklist) → done; the permissions step is skipped on Windows. `onboardingStep`/`hasOnboarded` keys kept. Also reachable from About.
6. **Feature catalog + runtime** (mirrors `FeatureCatalog`, `FeaturePresets`, `FeatureRuntime`). `AppFeature` with all 66 members and an explicit raw-value table (never `ToString()`), `FeatureGroup`, `FeatureCatalog` statics, `FeatureWindowsSupport.Classify` → Supported / Approximate / NotApplicable (Stage 1 supported: mixer, keepAwake, 6 monitors, notch, notchTimer, commandBar; approximate: soundOutputSwitcher; rest NotApplicable until ported; NotApplicable rows grey out like `fanControl` on a fanless Mac). `FeatureRuntime` with `Dictionary<AppFeature, Action>` of lazy bindings over `Lazy<T>` singletons, `SyncAtLaunch`, `SetAvailable`, presets, `NeedsRestartToUnload`, `RelaunchApp`.
7. **Settings storage** (mirrors `Defaults.swift`, `SettingsBackupSupport`, `SettingsBackup`, `LaunchAtLogin`). `DefaultsStore`: in-memory dictionary from `%LOCALAPPDATA%\Faqra\settings.json`; typed getters falling through to registered defaults; coalesced change event; 250 ms debounced atomic write (`.tmp` + `File.Replace` + `.bak`), flush on exit/`SessionEnding`; corrupt file → `.corrupt-<ts>` and fresh defaults. `DefaultsKey` keeps every upstream key string; `DefaultsSanitizers` ports `sanitized*`; `DefaultsMigrations` ports `register()`. Backup export/import as JSON with the same envelope keys so a macOS backup imports (unknown keys dropped, types checked). Launch at login: `HKCU\...\Run\Faqra` + `StartupApproved` state mapping (Enabled / NeedsApproval / Off); `StartupAction` logic ported.
8. **Command Bar** (mirrors `CommandBarService`, `CommandBarCatalog`, `CommandBarSupport`, `CommandBarMath/Units/Dates`). Default Alt+Space via `RegisterHotKey(MOD_ALT|MOD_NOREPEAT, VK_SPACE)` (pre-empts the system menu; PowerToys Run does the same); on failure fall back to Ctrl+Alt+Space and flag `ShortcutRegistrationFailed` in Settings. Window activates (WPF cannot type into a non-activated window) but `ForegroundRestorer` snapshots the caller and rows that type restore it before `SendInput`. Modes search/argument/confirm/actions; static catalog (actions, toggles from every Supported boolean feature, settings pages); providers: `AppsProvider` (`FOLDERID_AppsFolder` enumeration, icons via `IShellItemImageFactory`), `WindowsProvider` (`EnumWindows` filtered, `DWMWA_CLOAKED`), `AnswersProvider` (math/units/dates ported). `CommandBarSearch.Rank` ported verbatim; usage memory under `commandBarUsage`.
9. **Global shortcuts** (mirrors `GlobalShortcut.swift`, `HotkeyManager`, `ShortcutRecorderButton`). Same storage grammar (`control+option+shift+command:<vk>`, command→Win, option→Alt, keyCode = Windows VK; macOS keycodes rejected by the sanitizer → Windows default). `HotKeyRegistry` on a hidden HWND with `Suspend/Resume` for the recorder. `ShortcutConflicts`: in-app duplicates + `WindowsReservedShortcuts` table + runtime probe. `ShortcutRecorder` WPF control with key-cap rendering and conflict caption.
10. **Essential features.** *Mixer* (mirrors `AppVolumeMixer`, `MixerRoutingSupport`, `SoundOutputSwitcher`, `MixerSection`): NAudio `MMDeviceEnumerator` → sessions → `SimpleAudioVolume` + `AudioMeterInformation` for the live indicator; sessions grouped per process (`persistenceID` = AUMID or exe name); `appVolumes` persisted 0…1 (boost omitted); default output switch via `PolicyConfig.SetDefaultEndpoint`; per-app routing deferred. *Keep Awake* (mirrors `KeepAwakeManager`): `SetThreadExecutionState(ES_CONTINUOUS|ES_SYSTEM_REQUIRED[|ES_DISPLAY_REQUIRED])` on the UI thread, timer presets, battery-limit watchdog, connected-to-power automation via `WM_POWERBROADCAST`, pause-when-locked via `WTSRegisterSessionNotification`, tray variant + countdown. *Monitor* (mirrors `SystemMonitor`, `MetricFormat`, samplers, `MonitorSamplingPolicy`): CPU `\Processor Information(_Total)\% Processor Utility`; GPU `\GPU Engine(*)\Utilization Percentage` summed per adapter + `StabilizedGpuUsage`; RAM `GlobalMemoryStatusEx` with pressure thresholds; network `GetIfTable2` with a Windows interface exclusion list; disk `GetDiskFreeSpaceEx` + `\PhysicalDisk(_Total)` read/write; power `GetSystemPowerStatus` + `CallNtPowerInformation(SystemBatteryState)`; temperatures NotApplicable (rows hidden). 1/2/5 s cadence, samplers only run when something visible needs them.
11. **Diagnostics** (mirrors `Support/SelfTest.swift`, `Support/Uninstaller.swift`). `--selftest` (attach parent console; execution-state round trip, memory bounds, uptime, network monotonic, disk, power, settings round trip, tray glyph rasterization with `InkTouchesEdge`; prints `SELFTEST OK` / `SELFTEST FAILED: …`), `--uninstall` (Run key, StartupApproved, execution state, `--purge` for `%LOCALAPPDATA%\Faqra`), wired into the Velopack uninstall hook.
12. **Localization** (mirrors `Localization.swift`, `Strings+<Lang>.swift`, `*Strings.swift`). `AppLanguage` with the 13 raw values and `SystemDefault` rules; `Strings` as a sealed class with `required` properties (compile-time completeness like Swift's memberwise init); feature string bundles; `L10n.Shared.Language` + `Changed`; Stage 1 ships English, other 12 alias to English with a completeness test.

### E. Top risks

| Risk | Mitigation |
|---|---|
| Non-activating windows vs WPF keyboard input | Upstream's `takeFocus` split: hover never activates; keyboard paths activate explicitly; `ForegroundRestorer` returns focus before injected input. Prototype in M3 first. |
| Tray metric icons illegible / hidden in overflow | Render at real taskbar DPI, dense 7 px monospaced glyphs validated by the ink-edge self-test; tooltip + popover carry full text; stable `guidItem`. |
| Undocumented COM (IPolicyConfig, desktop pinning) | Only IPolicyConfig (stable since Vista) ships; every call wrapped in `TryX` with a visible "unsupported" state; pinning uses the documented re-show fallback. |
| PDH GPU counters missing/slow | Sum known engine types, cache the query, hide GPU when absent, compare with Task Manager in M4. |
